# Bank Smart Contracts Blockchain Project

A blockchain-based banking system using smart contracts to handle transactions, account management, and audit trails in a decentralized manner.

## Overview
This project demonstrates how smart contracts can be used to build a transparent and secure banking system. It includes contract deployment scripts, transaction handling, and a basic frontend for interaction.

## Tech Stack
- **Solidity** for smart contract development
- **Web3.js** for blockchain interaction
- **Truffle/Hardhat** for contract compilation and deployment
- **React** (optional) for the frontend interface

## Features
- Create and manage bank accounts
- Deposit and withdraw funds
- Transfer between accounts
- Transaction history and audit trail

## How to Run
```bash
# Install dependencies
npm install

# Compile contracts
npx hardhat compile

# Deploy to local network
npx hardhat run scripts/deploy.js --network localhost
```
